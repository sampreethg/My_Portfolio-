# Personal Portfolio

A clean, responsive personal portfolio website showcasing my projects, skills, and background.

🔗 **Live Demo:** https://myportfolio-mu-five-61.vercel.app/

---

## 🚀 Features

- **Responsive Design:** Optimized for desktops, tablets, and mobile devices.
- **Fast Performance:** Built using lightweight, pure HTML/CSS structure.
- **SEO & Discoverability:** Includes structured `sitemap.xml` and `robots.txt` configurations.
- **Projects & Experience:** Showcases featured works, technical toolsets, and contact details.

---

## 📁 Repository Structure

```text
├── index.html       # Main webpage structure and content
├── profile.jpeg     # Profile visual asset
├── robots.txt       # Search engine crawler instructions
├── sitemap.xml      # Site map for indexing
└── README.md        # Project documentation
🛠️ Tech Stack
Markup & Styling: HTML5 / CSS3

Hosting & Deployment: GitHub Pages

💻 Local Development
To run or edit this portfolio locally:

Clone the repository:

Bash
git clone [https://github.com/sampreethg/My_Portfolio-.git](https://github.com/sampreethg/My_Portfolio-.git)
cd My_Portfolio-
Open in browser:

Double-click index.html to view it in any modern browser, or

Serve using VS Code's Live Server extension or Python:

Bash
python3 -m http.server 8000
Navigate to http://localhost:8000.
